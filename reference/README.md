## 造型要点 / Design notes
- 比例:脚底→头顶 ≈ 0.84,耳尖 = 1.0;头宽 ≈ 0.57 × 头高 ≈ 0.44(大头,头身约 1:1)。
- 头:宽而圆,两侧脸颊有向外的尖簇毛;吻部微凸;眼周至两颊有更白的"面罩";粉色腮红。
- 耳:高大圆角三角,外倾约 25°,较厚;内侧凹陷为橙色绒面;耳根内侧有白色小凸点。
- 五官:深棕亮面椭圆眼 + 白色高光;深棕小三角鼻;"ω" 形微笑线。
- 身体:梨形(下宽上窄);短粗手臂/腿;爪、脚为橙色渐变,各 2 道趾缝(3 趾)。
- 围巾:橙红针织,绕颈一圈;垂端在角色左侧(画面右侧)胸前,下部 2 个斜向排列的小白方块。
- 尾巴:蓬松水滴形,尾尖约 1/4 橙色渐变。**原图尾巴透视错误(像贴在画面上的平面)— 3D 模型中改为真实透视:尾根在臀后中线,向后→向上弯并偏向角色左侧,长度比原图加长约 15%。**
- 材质:植绒/天鹅绒(sheen),柔和漫射光,浅灰背景 #ECEAE9,柔和地面阴影。
